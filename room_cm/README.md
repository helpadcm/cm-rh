# Meeting Rooms

El siguiente proyecto pretende sustituir la herramienta actual de booking de la sala principal del edificio XCALA.

## Requerimientos

### Código | Descripción | Estado

| **Código** | **Descripción**                                        | **Estado** |
|------------|--------------------------------------------------------|------------|
| **RN-1**   | Debe de existir el usuario administrador               |            |
| **RN-2**   | Debe existir el usuario estándar                       |            |
| **RN-3**   | Todos los usuarios deben de estar autenticados en Odoo |            |

### Código | Descripción | Estado

| **Código** | **Descripción**                                                          | **Estado** |
|------------|--------------------------------------------------------------------------|------------|
| **RU-1**   | El usuario administrador podrá eliminar reservas de todas las salas      |            |
| **RU-2**   | El usuario administrador podrá crear nuevas salas                        |            |
| **RU-3**   | El usuario estándar podrá hacer reserva de sala                          |            |
| **RU-4**   | El usuario estándar podrá eliminar reservas hechas por su propio usuario |            |

### Código | Descripción | Estado

| **Código** | **Descripción**                                      | **Estado** |
|------------|------------------------------------------------------|------------|
| **RF-1**   | Una sala solo se podrá reservar si no está reservada |            |
